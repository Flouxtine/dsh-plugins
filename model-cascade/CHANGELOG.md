# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-11-11

### Added

- Initial release of the `model-cascade` bundle: a left-sidebar panel that runs
  a two-stage model cascade. A strong decision model classifies the task, then
  either the small (simple) or strong (complex) model executes it.
